## About This Project

Final portfolio project for IS117 at NJIT. An aspirational professional portfolio for my target direction: **AI Forward Engineer**.

Built with Next.js 16, TypeScript, Tailwind CSS v4, and deployed to GitHub Pages via GitHub Actions.

---

## Process & Methodology

Built using the **spec-sprint methodology** from the course reference repository. Before a single page was coded, I wrote 9 phase specification documents covering every deliverable, component, and quality gate.

All documentation is in [`docs/specs/`](./docs/specs/).

### How I Used AI

AI was used as a collaborator throughout — research, spec review, component boilerplate, and debugging. All architectural decisions were made by me. Nothing shipped without being understood and verified.

## Tech Stack

| Layer | Technology |
