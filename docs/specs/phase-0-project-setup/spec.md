## Architecture Decisions

### Static Export

The site uses `output: 'export'` in `next.config.ts`. This produces a static
`out/` directory that GitHub Pages can serve directly. No server-side rendering
or API routes are needed for a portfolio.

### Path Aliases

All internal imports use `@/` as the root alias. This matches the reference
repo and keeps imports clean across deeply nested component files.

```ts
// tsconfig.json
{
  "compilerOptions": {
    "paths": {
      "@/*": ["./*"]
    }
  }
}
```

### No `src/` Directory

Files live directly at the root level: `app/`, `components/`, `lib/`,
`public/`. This matches the reference repo structure exactly.

npm run build
